# TypeScript Revision

This repository contains my topic-wise revision of TypeScript with
practical examples to strengthen fundamentals and prepare for interviews.

The goal of this repo is to build strong type-safety habits and understand
how TypeScript is used in real-world applications.

---

## 📚 What This Repository Contains

### 🔹 Core TypeScript Practice (`/src`)
Topic-wise examples covering:
- Basic Types
- Union & Any
- Type Narrowing
- Object Types
- Functions & Typing
- Interfaces
- Generics
- OOP Concepts
- HTTP Requests (fetch, axios)

Each file focuses on one concept with practical examples.

---

### 🔹 React + TypeScript Practice (`/reactts`)
A sandbox project to practice how TypeScript is used in React:
- Typing React components and props
- Custom hooks with TypeScript
- Shared types
- Component reusability

This folder is for learning and experimentation purposes.

---

## 🎯 Learning Objectives
- Understand TypeScript deeply, not just syntax
- Write type-safe and maintainable code
- Apply TypeScript in real-world scenarios
- Prepare for technical interviews
